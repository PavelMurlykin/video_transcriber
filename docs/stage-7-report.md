# Этап 7. Экспорт стенограмм

27.11.2026. Экспорт TXT, DOCX и PDF подключён к редактору и CLI.
Критерий этапа выполнен. Все три формата содержат одинаковый текст
отредактированного проекта с кириллицей, метками и метаданными.
Проверка проведена в проектной `.venv` с Python 3.13.12.
`python-docx 1.2.0`, `lxml 6.1.3` и `ReportLab 5.1.0` установлены
из wheel-файлов PyPI с проверкой SHA-256.

Экспорт использует текущий сохранённый снимок SQLite. Все три формата
получают метаданные, легенду и отсортированные по времени реплики из одного
шаблона. Дата начала обработки записывается в UTC при запуске медиаподготовки.
Старые проекты открываются без миграции и показывают неизвестную дату.
Готовый файл публикуется из временного файла в той же папке. Замена
существующего файла требует подтверждения в окне или флага CLI.

В PDF встраиваются обычный и полужирный DejaVu Sans из установленного
Matplotlib 3.10.6. Оригинальный текст лицензии хранится рядом со шрифтами.
[Лицензия DejaVu](https://dejavu-fonts.github.io/License.html)

## Ошибки и ограничения

До установки пакетов два теста DOCX и PDF пропускались. После установки
оба прошли в проектной среде. Для извлечения текста PDF использован pypdf
из комплектного Python Codex.

LibreOffice отсутствовал. В AppContainer запуск Word через COM вернул
`0x80070005`. Для проверки вёрстки только синтетический DOCX открыт в
настольном Word вне этого контейнера. Сопоставление содержимого реального
проекта выполнено в изолированной среде.

ReportLab 5.1.2 требует Pillow 13 или новее. Версия 5.1.0 из lock-файла
совместима с Pillow 11.3.0, уже установленным в проектной среде.
[Метаданные ReportLab 5.1.0](https://pypi.org/pypi/reportlab/5.1.0/json)

Обновлены [русское](user-manual.ru.md) и [английское](user-manual.en.md)
руководства. Приватные результаты проверок хранятся в `artifacts/`.
