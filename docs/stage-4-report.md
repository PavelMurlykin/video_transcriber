# Этап 4. Диаризация участников

26.11.2026. Критерий этапа выполнен. `DiarizationEngine` загружает локальную Community-1
и сохраняет исходную и эксклюзивную дорожки. В конфиге `transcribe`
доступны точное число, автоопределение и диапазон числа говорящих.
Два спикера остаются значением по умолчанию.

Номера присваиваются по первому появлению в исходной дорожке.
Сопоставление учитывает пересечения речевой разметки с интервалами слов.
Эксклюзивная дорожка помогает на границе реплик, если исходная разметка
подтверждает кандидата. При конфликте или слабой опоре код использует
`unknown` и пометку проверки. При смене говорящего фраза делится на
отображаемые сегменты. Слова без интервала сохраняют `null` и `unknown`.

Совместимые с JSON v1 поля `exclusive_diarization_turns` и
`overlap_regions` дополняют `diarization_turns`. Перекрытия вычисляются
по исходной дорожке, которая может содержать несколько голосов одновременно.
Файл `diarization.json` хранит `turns` и `exclusive_turns`.

## Проверка без сети

RTX 5070 Laptop, CUDA 12.8, PyTorch 2.8.0 и pyannote.audio 4.0.4.
Модели и пакеты использованы из существующего окружения. Windows AppContainer
блокировал TCP-пробы с `WinError 10013`, DNS тоже был недоступен.
Использован MP4 из `sample`, длительность подготовленного WAV 58,839 с.

| Режим | Время диаризации, с | Пик общей VRAM, МиБ | Пик RSS, ГиБ | Спикеров в исходной / эксклюзивной дорожках |
|---|---:|---:|---:|---:|
| Точно 2, полный прогон | 26,91 | 3841 | 1,79 | 2 / 2 |
| Авто | 28,73 | 3968 | 1,71 | 2 / 1 |
| Диапазон 2–3 | 27,75 | 3752 | 1,79 | 2 / 2 |

Для авто и диапазона отдельно запущен worker диаризации на том же
подготовленном WAV. В обоих случаях сохранено 15 исходных и 5 эксклюзивных
интервалов. Пик VRAM относится ко всей видеокарте, RSS — к дереву процессов.
Время включает загрузку и завершение worker.

Финальный полный прогон занял 90,44 с и сохранил два назначенных ID и
33 сегмента. В результате 144 слова с таймкодами и 5 с `null`. Из 15
исходных речевых интервалов выделено 10 областей перекрытия общей
длительностью 9,349 с. Эксклюзивная дорожка содержит 5 интервалов.
`check_run.py` вернул пустой список ошибок. Слова и пунктуация совпали
с исходным ASR. Хеши исходных MP3 и MP4 совпали с эталоном этапа 0.
Прежний JSON этапа 3 и новый результат прошли чтение и запись через
модель проекта v1 с сохранением всех полей.

Первая проверка авторежима ошибочно ожидала одинакового состава спикеров
в обеих дорожках. Фактический вывод модели содержал два исходных голоса и
один эксклюзивный. Повторная проверка требует, чтобы каждый эксклюзивный
спикер присутствовал в исходной разметке. Сведения об обоих голосах
сохранены в проекте.

Смена говорящего внутри фразы проверена тестами с полностью и частично
выровненными словами. Дополнительно два слова разных голосов
из реального выравнивания объединены в одну проверочную фразу.
Сведение с реальными интервалами Community-1 разбило её на два сегмента
и сохранило текст. Отдельно проверено, что полностью перекрывающиеся голоса
дают `unknown`, а интервалы перекрытия остаются в проекте.

Ручная эталонная разметка говорящих не использовалась. Результаты показывают
работу диаризации и согласованность полей, DER не измерялся.

```powershell

.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m compileall -q src scripts tests
.\.venv\Scripts\python.exe scripts\verify_offline.py --evidence artifacts\stage4-network-modes-final.json
.\.venv\Scripts\python.exe scripts\verify_offline.py --input 'sample\Дуэт Да.mp4' --run-dir artifacts\stage4-final --evidence artifacts\stage4-network-final.json
.\.venv\Scripts\python.exe scripts\check_run.py artifacts\stage4-final --expected-speakers 2 --expected-language ru --expect-overlap
```

**71 тест пройден**, `pip check` и компиляция модулей прошли. В одном
запуске после тестов `pyreadline3` сообщил об ошибке дескриптора консоли
при завершении. Код выхода pytest равен 0.

Метрики и результаты финального прогона находятся в
`artifacts/stage4-final/`. Для авто и диапазона использованы локальные
конфиги и копии подготовленного WAV в `artifacts/stage4-auto-final/` и
`artifacts/stage4-range-final/`. Результаты worker и замеры сохранены там же.
