# Этап 8. Автономность, ошибки и безопасность

27.11.2026. Критерий этапа выполнен. В Windows AppContainer без сетевых
возможностей и прав администратора прошёл цикл от запуска окна до
экспорта TXT, DOCX и PDF. Среда Python 3.13.12 и RTX 5070 Laptop.
На старте настольного клиента и перед обработкой проверяются FFmpeg,
ffprobe, свободное место и права записи, манифест с SHA-256 моделей и
выбранное вычислительное устройство. Отдельная проверка выполняет пробную
операцию PyTorch и проверяет тип вычисления CTranslate2 без загрузки весов.
Доступны диагностика из CLI и повторная проверка из настроек окна.

Пути конфигурации и ресурсов проверяются до использования. Windows
отклоняет UNC-пути и диски, подключённые по сети. Рабочие процессы
получают офлайн-переменные и окружение без токенов Hugging Face. В Pyannote
передаётся локальный путь к Community-1 и отключается использование токена.
Текст исключений библиотек и вывод рабочих процессов не записываются в
диагностику. Для ошибок доступны коды причин и подсказки.

## Проверки

- Регрессии. `100 passed` за 8,43 с. `compileall` и `pip check` прошли.
- Сквозной тест. `1 passed` за 217,84 с. Запись открыта по пути с
  латиницей и кириллицей. После принудительной остановки ASR восстановлен
  снимок подготовки аудио. Повтор завершился в новой папке.
- Проверка локальной среды на CUDA прошла в AppContainer. Обе TCP-пробы
  вернули Windows 10013, DNS недоступен.
- Точка входа настольного приложения автоматически показала сообщение
  об отсутствующем манифесте в проверочной локальной конфигурации.
- Проверка среды ASR с CPU и `int8` прошла за 8,75 с. Этот замер
  относится к проверке устройства и файлов.
- Регрессии ошибок покрывают отсутствующий FFmpeg, повреждённый манифест,
  нехватку дискового места, неверный UNC-путь, удаление токенов из окружения
  и блокирование Python DNS/TCP/UDP. Нехватка места имитировалась в тесте.

Проверка выходного JSON прошла. Из результата экспортированы два
спикера и 33 реплики. Правка после повторного открытия проекта
найдена в TXT, DOCX и извлечённом тексте двухстраничного PDF.
В захваченном выводе, журнале окна и шести технических файлах отсутствуют
имя входного файла, тестовая реплика и тестовый токен. Изоляция записана
в отдельном `network.json` прогона.

## Ошибки испытаний

В первом сквозном тесте поиск worker ограничивался прямыми потомками.
На Windows стартовый процесс `.venv` создаёт отдельный интерпретатор.
Поиск исправлен на проверку всего дерева текущего запуска. Отдельная
синтетическая проверка подтвердила завершение дочернего интерпретатора
при принудительной остановке запускающего процесса.

Повторный тест дошёл до открытия проекта после полного цикла. Тестовая
папка результатов оставалась только в памяти, поэтому новое окно открыло
каталог по умолчанию и показало модальный диалог. Настройки теперь сохраняются
перед запуском. При открытии проверяется путь к той же базе.
