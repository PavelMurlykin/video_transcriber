# Этап 9. Производительность на Legion Pro 5

27.11.2026. Замеры выполнены на Lenovo Legion Pro 5 16IAX10 с Intel Core
Ultra 7 255HX, NVIDIA RTX 5070 Laptop с 8151 МиБ VRAM и 31,43 ГиБ доступной
системе RAM. Использован драйвер 621.24 и существующее окружение Python
3.13.12. Базовый профиль Large V3 использует CUDA, float16 и батч 4.
Все четыре рабочих прогона завершились в этом профиле. Критерий этапа
выполнен. Ошибок выделения видеопамяти и секундных пауз в обработке
событий Qt не зарегистрировано. Повторный прогон прошёл проверку JSON.

## Записи

- 5 минут, два участника. Повторы предоставленного диалога без добавленного
  шума. Тот же WAV использован для повторной обработки.
- 30 минут, один участник. Три синтетические фразы локального голоса
  Microsoft Irina о цифровом аудио повторялись в минутном цикле.
  Добавлен белый шум с RMS 0,035 от полной шкалы и seed 182409.
- 90 минут, четыре исходных голоса. В 150-секундном цикле объединены
  предоставленный диалог и фразы двух местных голосов Microsoft Irina и
  Microsoft Pavel. В каждом цикле есть три заданных перекрытия и пауза
  37,84 с в конце.
- 60 секунд цифровой тишины для проверки поведения при отсутствии речи.

Все WAV имеют один канал, 16 кГц и 16-битный PCM. Записи предназначены
для оценки нагрузки. Коэффициенты WER и DER для этих повторов не измерялись.
Сценарии, расшифровки, контрольные снимки и метрики хранятся в
игнорируемом каталоге `artifacts/`.

## Метод

Скрипт `scripts/benchmark_desktop.py` запускает фактический PySide6-клиент
и проверяет отсутствие сетевых разрешений AppContainer и доступности TCP и
DNS перед каждым случаем. Время интерфейса измерено от нажатия «Начать»
до завершения. Учитывается максимальный интервал между срабатываниями
таймера Qt с заданным интервалом 50 мс. TCP-пробы отклонены с кодом Windows
10013, DNS недоступен.

Пик VRAM относится ко всей видеокарте. RSS суммируется по дереву CLI и
дочерних процессов. Интервал выборки памяти около 0,5 с, короткие фазы
получают хотя бы один замер. Время фазы включает её работу и сбор метрик.
При проверке JSON сравниваются ожидаемые язык, спикеры и перекрытия,
границы сегментов, метки слов и статусы обработки.

## Ошибки подготовки и тесты

Первый синтез прервался на вызове `Wait` для объекта `TaskAwaiter`.
При выборе метода WinRT добавлен фильтр по имени `AsTask`, после чего
оба установленных русских голоса сформировали WAV.

Прошёл 101 регрессионный тест за 5,35 с. Проверка зависимостей и компиляция
прошли. В одном раннем успешном запуске при завершении `pyreadline3`
сообщил о недействительном дескрипторе консоли `0xc0000008`.
