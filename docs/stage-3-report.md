# Этап 3. Временное выравнивание слов

26.11.2026. Критерий приёмки выполнен. Выравнивание использует ранее
подготовленные русские Wav2Vec2, процессор и данные NLTK из локальных
каталогов. Проверка прошла на RTX 5070 Laptop с CUDA 12.8 и прежним набором
зависимостей.

Модуль сопоставляет слова WhisperX с исходным текстом ASR по порядку и
проверяет границы каждого интервала после округления до миллисекунд.
Неполное выравнивание сохраняет исходный сегмент и пригодные интервалы слов.
Числа, неподдерживаемые буквы, пометки в скобках, неоднозначные повторы и
неподтверждённые интервалы получают `alignment_missing` и две метки
`null`. У сегмента устанавливаются `requires_review` и причина
`alignment_incomplete`. Кириллические аббревиатуры обрабатываются по
словарю модели. Для участка цифровой тишины используется исходный интервал
сегмента. Интерполяция меток отключена.

Формат JSON v1 сохранён. Сегменты с `null` проходят проверку и повторную
сериализацию через доменную модель. Эти поля образуют контракт для будущего
экспорта документов по этапу 7.

## Проверки без сети

| Запуск | Длина аудио | Выравнивание | Итог |
|---|---:|---:|---|
| Полная обработка предоставленного MP4 | 58,839 с | 20,81 с | 144 слова с интервалами, 5 с `null`, 33 сегмента, 2 назначенных спикера |
| Русская синтетическая запись с цифровой паузой | 7,574 с | 19,25 с | 6 слов с интервалами, 5 с `null`, два исходных интервала сегментов сохранены |

Полный прогон занял 90,82 с. На фазе выравнивания наблюдалось до 3203 МиБ
общей VRAM и 1,96 ГиБ RSS дерева процессов. После выхода worker наблюдалось
916 МиБ общей VRAM. В полном результате два сегмента отмечены
`alignment_incomplete`. Три из пяти слов с пропущенными метками содержат
цифры. Состав слов и знаков препинания в тексте совпал с исходным ASR.
Хеши исходных пользовательских MP3 и MP4 совпали с эталоном этапа 0.

В синтетическом примере число записано цифрами, кириллическая аббревиатура
произнесена по буквам, текст содержит пометку о неразборчивой речи.
К 5,574 с речи добавлено 2 с цифровой тишины. Метки числа, пометки и слова
в тишине остались `null`. У аббревиатуры есть интервал. Проверка показывает
согласованность временных интервалов, точность меток по ручной разметке
отдельно не измерялась.

Обе проверки выполнены в Windows AppContainer без сетевых разрешений.
TCP-пробы отклонены с `WinError 10013`, DNS недоступен. В первом синтетическом
прогоне после очистки кэша PyTorch показывал 1,18 ГиБ выделенной памяти.
Явное удаление ссылок на модель и процессор вернуло показатель в повторном
прогоне к 8,13 МиБ. Это показатель аллокатора внутри worker. Общая VRAM
включает также другие приложения.

## Команды и результаты

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:debugging --durations=5
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m compileall -q src scripts tests
.\.venv\Scripts\python.exe scripts\verify_offline.py --evidence artifacts\stage3-network-fixture-final.json
.\.venv\Scripts\python.exe -m local_transcriber.workers.transcription_worker alignment --config config.local.json --run-dir artifacts\stage3-fixtures\edge-alignment-final
.\.venv\Scripts\python.exe scripts\verify_offline.py --input 'sample\Дуэт Да.mp4' --run-dir artifacts\stage3-final --evidence artifacts\stage3-network-final.json
.\.venv\Scripts\python.exe scripts\check_run.py artifacts\stage3-final --expected-speakers 2 --expected-language ru
```

Прошли все **54 теста**, `pip check` и компиляция модулей. В одном запуске
после прохождения тестов `pyreadline3` сообщил об ошибке закрытия дескриптора
консоли. Код выхода pytest равен 0. Итоговая проверка JSON вернула пустой
список ошибок. Локальные метрики и результаты находятся в
`artifacts/stage3-final/` и `artifacts/stage3-fixtures/edge-alignment-final/`.
При повторе полной обработки укажите новый каталог `--run-dir`.
