# Этап 10. Упаковка для Windows

28.11.2026. Сборка подготовлена на Windows 11 Pro 26H1 x64 под Python
3.13.12 с PyInstaller 6.22.3 и Inno Setup 7.1.1. SHA-256 пакетов сборки
сверены с PyPI и официальным релизом Inno Setup. Новые пакеты Python
установлены в `.venv`. Компилятор Inno Setup размещён в `.tools`.

## Сборка

После подготовки существующей `.venv`, локальных колёс с PyPI и FFmpeg
9.0.2 Essentials выполните из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pip install --no-index --no-deps --require-hashes --find-links .tools\stage10-wheels -r requirements-packaging.lock
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts\build_windows.py --ffmpeg-root .tools\ffmpeg-9.0.2-essentials_build --iscc .tools\inno-7.1.1\ISCC.exe --output artifacts\windows-build
```

Задайте новый каталог для каждого запуска. Сборка использует локальные
библиотеки и не обращается к сети. Скрипт формирует два EXE с общим
каталогом `_internal`. Графический запуск использует приложение без
консоли. Консольный EXE принимает CLI-команды и запускает отдельные
процессы для проверки CUDA, ASR, выравнивания и диаризации. Так сохраняются
передача статусов интерфейсу и последовательная загрузка моделей.

Inno Setup устанавливает для текущего пользователя, создаёт ярлык в
меню «Пуск» и предлагает ярлык на рабочем столе. Модели остаются вне
пакета. EXE установщика и файл `.bin` нужно хранить рядом.
Конфигурация, базы проектов и расшифровки хранятся отдельно от
каталога установки. Клиент удаляет временный кэш рабочей фазы после
обычного выхода процесса и после отмены. Лицензии и сведения о
компонентах находятся в `_internal\third-party-notices.txt` и
`_internal\licenses`.

Итоговая сборка хранится в `artifacts/stage10-build-04/installer/`.
Размер EXE и файла данных вместе составляет 2,97 ГиБ. Установщик
собран за 191,31 с.

## Приёмка

- 103 регрессионных теста прошли. Проверка зависимостей и компиляция Python
  прошли.
- Интеграционный тест исходного клиента в AppContainer прошёл за 169,24 с.
- PyInstaller собрал комплект `onedir` размером 5,14 ГиБ. В AppContainer
  встроенный CLI прошёл `check-runtime` на CUDA с системным `PATH`, без
  интерпретатора Python из `.venv`. Проверены локальные модели и
  загружаемые DLL PyTorch и CTranslate2.
- Комплект после добавления метаданных TorchCodec прошёл полный цикл
  в AppContainer. На тестовой записи получено 34 сегмента с двумя
  спикерами за 105,04 с. Пик VRAM на ASR составил 5187 МиБ, пик RSS
  дерева процессов составил 3,59 ГиБ. Экспорты TXT, DOCX и PDF созданы
  из сохранённого проекта. Временные каталоги фаз удалены.
- Inno Setup проверил синтаксис файла установки, иконку и оба языка на
  небольшой тестовой сборке.
- Графический EXE открыл окно в текущем профиле. Windows UI Automation
  подтвердил сообщение «Локальная среда проверена» после запуска
  консольного EXE из интерфейса.
- В обычном текущем профиле Inno Setup создал ярлык и запись удаления за
  130,09 с. Деинсталляция за 2,38 с удалила программу, ярлык и запись
  удаления. Контрольный файл проекта сохранил исходный SHA-256.
- Итоговый пакет установлен в текущем профиле за 128,93 с.
  Установленный CLI запущен в AppContainer с новым каталогом данных и
  `PATH`, ограниченным System32. Две прямые TCP-пробы отклонены с кодом
  WinSock 10013. DNS недоступен. Внешний Python отсутствовал в `PATH`.
  Запись длительностью 58,84 с обработана на CUDA за 99,94 с.
  Получено 34 сегмента с двумя спикерами, проверены все фазы и три
  формата экспорта. Пики ASR составили 5224 МиБ VRAM и 3,57 ГиБ RSS
  дерева процессов. Временный кэш фаз удалён.
- Окно итоговой установленной сборки подтвердило готовность среды
  в текущем профиле. Деинсталляция за 2,26 с удалила программу,
  ярлык и запись удаления. SHA-256 базы проекта, JSON и конфигурации
  совпали до и после удаления.
- Отдельный новый профиль Windows остаётся условием окончательной
  приёмки. Запрошено разрешение на временную стандартную учётную запись
  для [проверки](testing.md#windows-installer-acceptance). Коммит и
  публикация ожидают этой проверки.

Первый запуск сборщика остановился на поиске метаданных пакета
`PySide6`. В существующей среде установлены `PySide6_Essentials` и
`PySide6_Addons`. Спецификация сборки теперь берёт метаданные этих
компонентов и `shiboken6`.

В первой полной сборке проверка CUDA прошла, а рабочий процесс ASR
завершился с `ModuleNotFoundError`. WhisperX загружает `whisperx.asr`
и `whisperx.alignment` при вызове функций. Оба модуля добавлены в
спецификацию PyInstaller.

Следующая сборка нашла эти модули, но Transformers остановился при
проверке версии TorchCodec. В комплект добавлены метаданные TorchCodec.
Само декодирование выполняет включённый FFmpeg. Community-1 получает PCM
как тензор и не использует декодер TorchCodec.

Запуск Inno Setup внутри AppContainer распаковал содержимое, затем
откатил установку. Контейнер заблокировал запись ярлыка и ключа
деинсталлятора в HKCU с кодом Windows 5. Для приёмки установки нужен
обычный профиль Windows с сетевой изоляцией на уровне ОС.
