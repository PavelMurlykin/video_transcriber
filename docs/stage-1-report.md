# Этап 1. Доменная модель и медиаподготовка

26.11.2026. Этап прошёл проверку по [ТЗ](../Local_Transcriber_Codex_Development_Plan.md)
на Windows 11, Python 3.13.12, FFmpeg/ffprobe 9.0.2 и RTX 5070 Laptop.

В доменной модели появились `Project`, `Speaker`, `Segment`, `Word`,
`TranscriptionJob` и `StageStatus`. JSON транскрипции сохранил версию 1.
Два фактических JSON этапа 0 и новый JSON этапа 1 прочитаны и записаны через
новую модель с совпадением всех полей. Исходные результаты распознавания и
выравнивания хранятся отдельно от редактируемых сегментов. Статусы фаз
записываются в технические метрики.

`prepare-media` проверяет вход через ffprobe, оценивает место на диске с резервом
16 МиБ и извлекает первую аудиодорожку в PCM WAV 16 бит, 16 кГц, один канал.
FFmpeg и ffprobe запускаются со списками аргументов. Извлечение идёт во временный
подкаталог. Ошибка или отмена удаляет частичный файл. При транскрибации рабочий
WAV удаляется после сохранения JSON. Отдельная команда медиаподготовки сохраняет
WAV как результат. Размер WAV ограничен форматом RIFF примерно 4 ГиБ.

| Сценарий | Результат |
|---|---|
| MP3 и MP4 из `sample`, кириллица и пробелы | Обе команды `prepare-media` извлекли по 58,839 с. Источники определены как MP3 и AAC |
| Синтетический MKV, 60 минут, MPEG-4 и FLAC | Извлечено 57 600 000 аудиосэмплов. Тест с генерацией файла занял 0,52 с |
| Аудиофайл с IMA ADPCM | CLI распознал кодек и создал WAV PCM 16 кГц mono |
| Видео без аудио и повреждённый контейнер | Получены ожидаемые `NO_AUDIO_STREAM` и `INVALID_MEDIA` |
| Нехватка места и прерывание | При имитации заполненного диска FFmpeg не запущен. После сигнала отмены дочерний FFmpeg завершён, частичный WAV удалён |
| Сохранность входных файлов | SHA-256 исходных MP3 и MP4 совпали с хешами этапа 0 |

## Полный офлайн-прогон

MP4 из `sample` прошёл ASR, выравнивание, диаризацию и сведение за 114,03 с.
Сетевые пробные подключения в Windows AppContainer отвергнуты с WinError 10013,
DNS недоступен. JSON прошёл структурную проверку с двумя назначенными
спикерами, 56 сегментами и 149 словами с временными метками. 29 сегментов
помечены для ручной проверки. Рабочий WAV и временный подкаталог удалены.

| Фаза | Время, с | Наблюдаемый пик VRAM, МиБ | Пик RSS, ГиБ |
|---|---:|---:|---:|
| Медиаподготовка | 0,123 | — | — |
| ASR | 62,124 | 6277 | 3,56 |
| Выравнивание | 21,246 | 3344 | 1,14 |
| Диаризация | 27,144 | 3583 | 1,79 |
| Сведение и запись JSON | 0,019 | — | — |

VRAM измерена для всей видеокарты, RSS для дерева процессов. Общее время
включает проверку хешей моделей. Для часового файла измерена медиаподготовка.
Сценарий отмены проверен сигналом через API с реальным дочерним FFmpeg.

## Команды проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:debugging --durations=6
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m local_transcriber --config .tools/ffmpeg-install.json prepare-media 'sample\Дуэт Да.mp3' --run-dir artifacts\stage1-mp3
.\.venv\Scripts\python.exe -m local_transcriber --config .tools/ffmpeg-install.json prepare-media 'sample\Дуэт Да.mp4' --run-dir artifacts\stage1-mp4
.\.venv\Scripts\python.exe scripts\verify_offline.py --config config.local.json --input 'sample\Дуэт Да.mp4' --run-dir artifacts\stage1-offline --evidence artifacts\stage1-network.json
.\.venv\Scripts\python.exe scripts\check_run.py artifacts\stage1-offline --expected-speakers 2
```

Прошли все 33 теста. `pip check` не выявил конфликтов. В обоих руководствах
описаны команда медиаподготовки, коды ошибок, отмена и жизненный цикл WAV.
Подробные локальные результаты сохранены в `artifacts/stage1-offline/`.
